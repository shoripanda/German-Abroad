# Publishing Skills

このディレクトリは過去の出版プロジェクトで蓄積した編集ノウハウを再利用可能な形で保持する。

## スキル群
- natural-japanese：AI臭を抑え、自然な日本語にする
- memoir-writing：インタビュー素材を具体的な体験記へ変換する
- interview：記憶を掘り起こす半構造化インタビュー
- citation：引用・典拠管理
- fact-check：事実確認・創作防止
- cover-design：AI臭の少ない表紙・背・裏表紙
- adversarial-review：完成稿を敵対的に検証する
- terminology：固有名詞・外国語の日本語表記
- page-design：文字数・四六判ページ数管理

源流は shoripanda/German-book と shoripanda/university。今後、原資料を精読しながら各スキルを統合・更新する。
